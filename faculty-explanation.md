# LMS Portal Demo - Faculty Explanation

## Overview
This project is a React-based Learning Management System (LMS) demo website. It is designed to showcase how a student-facing learning portal can look and function.

The website includes multiple pages such as:
- Home
- Courses
- Live Virtual Class
- External Data
- Login

## Purpose of the Website
The project demonstrates:
- Modern UI design for an LMS portal
- Navigation between different sections
- Course listing and registration flow
- Live class page layout
- External API data fetching
- Basic frontend form handling

## Main Pages

### 1. Home Page
The home page introduces the portal and highlights key LMS features such as:
- Course Management
- User Management
- Assignments
- Gradebook

### 2. Courses Page
This page displays several training programs including:
- MEAN Stack Development
- MERN Stack Development
- Java Programming
- GenAI for Developers

It also includes a registration form where a user can enter their details and select a course.

### 3. Live Virtual Class Page
This page is designed as an interactive learning section. It includes:
- Hero/banner section
- Course details
- Registration section
- Photo gallery
- Blog section
- Help section
- Contact section

### 4. External Data Page
This page fetches sample user data from the JSONPlaceholder API and displays it in a table. It demonstrates:
- API integration
- Loading state
- Error handling
- Data rendering

### 5. Login Page
The login page is a simple demo form. It collects an email and password, but it does not connect to a real authentication backend.

## Login Credentials
There is currently no real login authentication system implemented.

For demo purposes, any dummy credentials can be used, for example:
- Email: demo@lms.com
- Password: 123456

You may also use any other sample values such as:
- Email: student@example.com
- Password: password

## Technical Stack
The website is built using:
- React
- React Router
- CSS
- JavaScript
- Fetch API for external data

## Current Status
This is a frontend demo project. It is suitable for:
- UI demonstration
- Presentation purposes
- Learning and practice

It does not yet include:
- Full backend authentication
- Real database integration
- Role-based access control
- Live course enrollment backend

## How to Run
From the frontend folder, run:

```bash
npm start
```

Then open the local React development URL in the browser.

## Faculty Summary
This LMS portal is a demo application that showcases how an educational platform could look and behave. It demonstrates course browsing, registration forms, live class presentation, and external data integration. The login feature is currently a UI demo and does not use a real authentication system.
